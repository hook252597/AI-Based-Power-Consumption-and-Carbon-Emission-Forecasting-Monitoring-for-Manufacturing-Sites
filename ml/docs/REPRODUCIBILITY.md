# 재현 가능한 범위

## 이 묶음만으로 가능한 일

- 저장 모델로 미래 시간대 전력·요금·탄소 예측.
- 규격에 맞는 새 센서 CSV에 모델 점수·판정 및 문서 규칙 판정 부여.
- 원본을 읽지 않는 단위 테스트 실행.
- 후보 비교표, 선택 절차, 당시 평가 결과 확인.

`src/manufacturing_ai`에는 실제 실험에 사용한 학습·평가 함수가 포함되어 있습니다. 전력 V2는 입력·출력 경로를 명시하는 재학습 도구도 제공합니다. 이상탐지 전체 재학습은 별도의 연구 캐시·이전 모델이 필요합니다.

## 전력 V2 재학습

`scripts/train_forecast_v2.py`에 학습용 시간 집계와 5월 평가 정답을 지정합니다. `ml/`에서 실행하는 예입니다.

```powershell
.\.venv\Scripts\python.exe scripts/train_forecast_v2.py --hourly local_data/hourly_observed.csv --reference ../data/rtu_ground_truth_may.csv --output-dir runs/forecast_check/results --model-dir runs/forecast_check/models
```

`local_data/`와 `runs/`는 저장소 추적 대상에서 제외합니다. 빈 출력 폴더를 사용해 공유된 실험 결과를 보존하세요. 5월 정답은 학습·선택이 끝나고 모델과 예측을 저장한 뒤 비교에만 읽습니다.

시간 집계 파일의 필수 컬럼은 `module(equipment)`, `datetime`, `n`, `power_count`, `power_sum`입니다. `datetime`은 한국 현지 시간 문자열, `n`은 5초 기록 수, `power_count`는 유효 전력 기록 수, `power_sum`은 그 시간의 `activePower`(W) 합계입니다. 13개 설비의 2024-12-01 00:00~2025-04-29 23:00 자료와 시간별 720개 기록이 필요합니다. 마지막 4월 30일 00시의 불완전 기록만 제외합니다. 원본을 무작위 분할하거나 정상 행만 남긴 뒤 집계하지 않습니다.

4개 AI 모델군의 12개 설정과 평균·중앙값 비교 기준은 실행 전에 `protocol.json`에 기록합니다. 3월 MAE로 AI만 선택하고 4·5월은 재평가합니다. `summary.json`은 지표 정의, 선택 모델, 비교 결과, 저장 전후 추론 일치와 입력 파일 보존 점검을 포함합니다.

## 전체 재학습에 추가로 필요한 것

1. 원본 `rtu_data_full.csv`와 표시본 `rtu_data_full_flagged.csv`. 대용량이므로 묶음에 포함하지 않았습니다.
2. 전력 학습용 시간 집계: 설비·시간별 720개의 5초 기록을 확인하고 W→kWh로 변환해야 합니다. 마지막 불완전 시간은 제외합니다.
3. 5월 전력 평가용 `rtu_ground_truth_may.csv`. 모델 선택에는 사용하지 않습니다.
4. 이상탐지 v1 캐시 생성 및 13개 기본 모델 학습. v2는 이 캐시와 기본 모델을 이용합니다.
5. 개인 경로에 의존하지 않는 실행 경로 설정과 빈 실험 출력 폴더. 재생성한 원본 파일의 수정시각 등이 달라지면 기존 실험 식별값과 일치하지 않으므로 기존 결과 폴더를 덮어쓰지 않습니다.

기존 로컬 `run_all.ps1`, `train_anomaly_v2.py`, EDA 전체 실행 스크립트는 위 자료가 없으면 동작하지 않아 공유 묶음에서 제외했습니다. 전력 V2는 위 재학습 도구로 실행할 수 있고, 이상탐지는 연구 캐시와 전용 실행 도구를 추가로 연결해야 합니다. `data/`에 있는 5월 정답 하나만으로 전체 학습을 재현할 수 없습니다.

## 실험 기록과 배포 파일의 구분

- `outputs/anomaly_v2/protocol.json`: 후보와 시간 분리·선택 규칙.
- `selection.json`: 3월 후반에서 고정한 후보 선택.
- `april_evaluation_gate.json`: 4월 재평가 전에 저장한 원본 연구 모델·선택 파일 해시.
- 배포 모델은 추론에 사용하지 않는 비교용 탐지기를 제거한 내보내기 파일입니다. 학습 결과·선택된 탐지기의 점수·임계값은 그대로입니다.
- 연구 당시 원본 모델 해시와 배포 모델 해시는 서로 다릅니다. `models/anomaly_v2/export_manifest.json`에서 두 해시와 예측 동등성 검증을 확인합니다.

모델 파일을 줄인 것은 재학습이나 성능 개선이 아닙니다. 새로운 독립 데이터 검증도 아닙니다. 4월 결과를 확인하고 개선을 설계했으므로 해당 점수는 탐색적 재평가로 계속 표시합니다.
