# 재현 가능한 범위

## 이 묶음만으로 가능한 일

- 저장 모델로 미래 시간대 전력·요금·탄소 예측.
- 규격에 맞는 새 센서 CSV에 모델 점수·판정 및 문서 규칙 판정 부여.
- 원본을 읽지 않는 단위 테스트 실행.
- 후보 비교표, 선택 절차, 당시 평가 결과 확인.

`src/manufacturing_ai`에는 실제 실험에 사용한 학습·평가 함수도 포함되어 있습니다. 다만 전체 실험 실행 함수는 연구 당시의 데이터·캐시·이전 모델 배치를 전제로 합니다. 이 묶음에서는 추론 CLI만 실행 진입점으로 제공합니다.

## 전체 재학습에 추가로 필요한 것

1. 원본 `rtu_data_full.csv`와 표시본 `rtu_data_full_flagged.csv`. 대용량이므로 묶음에 포함하지 않았습니다.
2. 전력 학습용 시간 집계: 설비·시간별 720개의 5초 기록을 확인하고 W→kWh로 변환해야 합니다. 마지막 불완전 시간은 제외합니다.
3. 5월 전력 평가용 `rtu_ground_truth_may.csv`. 모델 선택에는 사용하지 않습니다.
4. 이상탐지 v1 캐시 생성 및 13개 기본 모델 학습. v2는 이 캐시와 기본 모델을 이용합니다.
5. 개인 경로에 의존하지 않는 실행 경로 설정과 빈 실험 출력 폴더. 재생성한 원본 파일의 수정시각 등이 달라지면 기존 실험 식별값과 일치하지 않으므로 기존 결과 폴더를 덮어쓰지 않습니다.

기존 로컬 `run_all.ps1`, `train_anomaly_v2.py`, EDA 전체 실행 스크립트는 위 자료가 없으면 동작하지 않아 공유 묶음에서 제외했습니다. 팀원이 재학습할 때는 이 자료를 준비한 뒤 실행 경로를 명시하는 별도 실행 도구를 연결해야 합니다. `data/`에 있는 5월 정답 하나만으로 전체 학습을 재현할 수 없습니다.

## 실험 기록과 배포 파일의 구분

- `outputs/anomaly_v2/protocol.json`: 후보와 시간 분리·선택 규칙.
- `selection.json`: 3월 후반에서 고정한 후보 선택.
- `april_evaluation_gate.json`: 4월 재평가 전에 저장한 원본 연구 모델·선택 파일 해시.
- 배포 모델은 추론에 사용하지 않는 비교용 탐지기를 제거한 내보내기 파일입니다. 학습 결과·선택된 탐지기의 점수·임계값은 그대로입니다.
- 연구 당시 원본 모델 해시와 배포 모델 해시는 서로 다릅니다. `models/anomaly_v2/export_manifest.json`에서 두 해시와 예측 동등성 검증을 확인합니다.

모델 파일을 줄인 것은 재학습이나 성능 개선이 아닙니다. 새로운 독립 데이터 검증도 아닙니다. 4월 결과를 확인하고 개선을 설계했으므로 해당 점수는 탐색적 재평가로 계속 표시합니다.
