# Design — 마가렛트 전력·탄소 모니터링 대시보드

## 1. 기술 스택 / 실행
- **프레임워크**: Streamlit (Python), 단일 파일 `dashboard_app.py`로 실행 가능.
- **차트**: Plotly (`plotly.graph_objects` 중심). 버전 고정, 실행 방법은 코드 맨 위 주석에 기재.
- **레이아웃**: `st.columns` + CSS 주입(`st.markdown(..., unsafe_allow_html=True)`)으로 고정 폭 영역 구성.
- **기준 해상도**: 1366 × 768. 세로 스크롤 없이 한 화면.
- **상태 관리**: `st.session_state`에 전역 상태 보관 — `selected_month`, `selected_day`, `active_tab`, `theme(light/dark)`, `selected_equipment`, `anomaly_view(daily/monthly)`, `thresholds`, `chat_history`, `report_values`.
- **고정 기준일**: "오늘" = 2025-05-31.

## 2. 전체 화면 배치 (4개 영역)
`dashBoardSection.png` 기준. ①②③은 전 페이지 고정, ④만 교체.

```
┌─────────────────────────────────────────────────────────┐
│ ① 헤더 (전체폭, 64px)                                      │
├──────────┬──────────────────────────────────────────────┤
│          │ ③ 탭 (48px)                      [라이트][다크] │
│ ② 필터·  ├──────────────────────────────────────────────┤
│  설비목록 │                                               │
│ (240px)  │ ④ 본문 (약 1126 × 656px)                       │
│          │                                               │
└──────────┴──────────────────────────────────────────────┘
```

- **① 헤더**: 좌측 프로젝트명 "마가렛트"(크게) + 한 줄 설명 "AI 기반 제조 현장 전력량·탄소 배출량 예측 및 모니터링"(작게). 우측 끝 "제작" 라벨 + "박정열 · 김민찬 · 최경철".
- **② 필터·설비목록 (240px)**: 상단에 월 드롭다운 / 일 드롭다운(위아래 2줄). 아래 "설비 현황 13 · 이상 N" 요약, 그 아래 설비 13개 목록(행 54px, 이름 + 소비량 + 상태 원). 스크롤 없이.
- **③ 탭 (48px)**: 좌측 탭 3개(현황·예측 / 이상탐지[배지] / 에이전트), 우측 끝 라이트·다크 토글.
- **④ 본문**: 활성 탭에 따라 교체.

## 3. 탭 구성

### 탭 1 — 현황·예측 (본문 세로 16 / 42 / 42%)
`dashBoardEquipmentStatus*.png` 기준.

**(1) KPI 카드 4개 (16%, 가로 25%씩)**
| 카드 | 큰 숫자(금월 예상) | 보조(전월 대비) | 보조(일일 누적) |
|------|-------------------|----------------|----------------|
| 1 전기 요금 | 11,669,400 원 | ▲8.2% 빨강 | 오늘 294,480 원 |
| 2 전력 소비량 | 64,830 kWh | ▲8.2% 빨강 | 오늘 1,636 kWh |
| 3 탄소 배출량 | 27,488 kgCO2 | ▲8.2% 빨강 | 오늘 693.7 kgCO2 |
| 4 AI 예측 오차(MAE) | 4.3 kWh/시간 | — | "예측이 실제와 시간당 평균 4.3 kWh 차이" 한 줄 설명 |
- 전월 대비: 증가 빨강↑ / 감소 초록↓.

**(2) 꺾은선 그래프 3개 (42%, 가로 3등분, marker + 범례)**
- 그래프1 시간별 전력량: x 0~24시, y kWh
- 그래프2 월별 전력 추이: x 1~30일, y kWh
- 그래프3 월별 탄소 배출량 추이: x 1~30일, y kgCO2
- 공통: 실제=녹색 실선, 예측=파랑 점선, 점에 마우스 올리면 (시각, 값) 툴팁.

**(3) 하단 (42%, 좌 55% : 우 45%)**
- 좌 — 설비별 전력 사용 가로 막대: 컬럼 순위/설비명/소비량(kWh)/비율(%), 소비량 내림차순, 설비 13개 전부, 이상 설비는 왼쪽 빨간 띠, 넘치면 영역 내부만 세로 스크롤.
- 우 — 도넛 3개(가로): "상전압 이상(일일 기준)" / "선간전압 이상(일일 기준)" / "역률 이상(일일 기준)". 정상 초록 + 이상 빨강, 합=13, 중앙에 이상 건수, 아래 "정상 N / 이상 M". 이상 0건이면 전체 초록 + "이상 없음". 제목 문구 변경 금지.

### 탭 2 — 이상탐지 (본문 세로 12 / 29 / 29 / 29%)
`dashBoardDailyAnomalyStatus*.png`, `dashBoardMonthlyAnomalyStatus*.png` 기준.

**(1) 상단(12%)**: 설비 선택 버튼 13개(한 줄, 넘치면 줄바꿈, 단일 선택, 선택 버튼 색 채움, 이상 설비 빨간 점). 우측 끝 "일일 기준 / 한달 기준" 토글(기본 일일). 선택 설비는 전역 상태 공유.

**(2) 일일 기준 — 3행 3열**
| | 1열 | 2열 | 3열 |
|---|---|---|---|
| 1행 상전압(임계 210V) | 일일 R선 | 일일 S선 | 일일 T선 |
| 2행 선간전압(임계 360V) | 일일 RS | 일일 ST | 일일 TR |
| 3행 역률(임계 85%) | 일일 R | 일일 S | 일일 T |
- 공통: x 0~24시, marker 꺾은선, 측정 선 **전부 녹색 한 색**. 임계 가이드=빨간 점선, 임계 미만 영역=옅은 붉은 배경 띠, 임계 벗어난 점=빨강 강조. 제목 옆 임계치 표기. 데이터 없으면 "데이터 없음". 그래프 1개 약 363×176px.

**(3) 한달 기준 — 세로 3개 스택(가로 꽉 채움)**
- 한달 상전압(임계 210V): R 갈색 / S 검정 / T 회색
- 한달 선간전압(임계 360V): RS 적색 / ST 황색 / TR 청색
- 한달 역률(임계 85%): R 갈색 / S 검정 / T 회색
- x 1~30일, 각 점 = 그 상의 그 날 **최저값**, 임계 밑돌면 그 날 이상. 임계 미달 점은 크게 + 빨간 테두리.
- 선간전압 RS(적색)와 임계선(빨강) 겹침 → 임계선은 더 굵고 성긴 점선 + 배경 띠로 구분.
- 다크 모드: 검정 선만 밝은 흰색 계열로 교체(범례 이름 유지). 제목 옆 색 표식 범례 필수.

### 탭 3 — 에이전트 (본문 좌 45% : 우 55%, 상하 분할 없음)
`dashBoardAgent*.png` 기준.

- **좌 상단 — 체크리스트**: 진행률 한 줄("8 / 12 완료"), 클릭 시 펼침. 항목은 보고서 양식 중 '사람 입력' 항목에서 생성. 채워진 항목은 체크 + 값 축약.
- **좌 하단 — 대화**: 사용자 오른쪽/에이전트 왼쪽 말풍선, 입력창 하단 고정. 진입 시 오늘 이상 요약을 에이전트가 먼저 발화. 임계치 변경 요청 시 재분석 카드(예: "역률 85% → 90% 재분석 / 이상 2건 → 5건 / 새로 포함 사출기 A·B, 프레스 1" + [이상탐지에 반영][되돌리기]).
- **우 — 보고서 미리보기**: "제조현장 안전 점검 보고서" 양식, 항목 순서·이름 그대로. 자동 채움(전력/요금/탄소 등) vs 사람 입력 구분. 미입력='(미입력)' 흐리게, 방금 채운 항목 잠깐 강조. 우상단 양식명 + 내보내기(필수 다 차야 활성화).

## 4. 사용할 데이터 파일
| 용도 | 경로(명세) | 비고 |
|------|-----------|------|
| 학습 데이터 | `training-datasets/rtu_data_full.csv` | 2024-12 ~ 2025-04, 5초 간격 원시 측정 |
| 검증(실측) | `may-datasets/rtu_ground_truth_may.csv` | 2025-05 시간당 집계 |
| 레포 내 실제 파일 | `data/rtu_ground_truth_may.csv` | 컬럼: id, hourly_pow, may_bill, may_carbon, agg_pow |
| 레포 내 플래그 원시 | `rtu_data_full_flagged.csv` (.gitignore 대상) | module(equipment), timestamp, localtime, operation, voltageR/S/T, voltageRS/ST/TR, currentR/S/T, activePower, powerFactorR/S/T, reactivePowerLagging, accumActiveEnergy, is_outlier, outlier_reason |

- **대체**: 명세 경로 파일이 없으면 같은 구조의 **더미 데이터 생성**으로 화면을 채운다(설비 13개, 5초 간격, 전압/역률/전력 포함).
- **파생 계산**: 전력량 kWh = activePower × 5/3600 누적 합 / 요금 = kWh × 180원 / 탄소 = kWh × 0.424 kgCO2.
- **예측**: 2025-05-10 00:00 ~ 2025-05-31 00:00, 1시간 단위. 모델은 LSTM/XGBoost/Prophet/SARIMA 중 MAE 최적.

### 설비 13개 (이름·순서·채널번호 고정)
`1 (PM-3)` · `2 (L-1전등)` · `3 (분쇄기(2))` · `4 (분쇄기(1))` · `5 (좌측분전반)` · `11 (우측분전반1)` · `12 (4호기)` · `13 (3호기)` · `14 (2호기)` · `15 (예비건조기)` · `16 (호이스트)` · `17 (6호기)` · `18 (우측분전반2)`

### 임계치 (기본값)
- 상전압 R/S/T: 210V 미만 이상
- 선간전압 RS/ST/TR: 360V 미만 이상
- 역률 R/S/T: 85% 미만 이상
- 이상치 탐지: 학습 데이터 삽입 이상치를 Isolation Forest 등으로 탐지.

## 5. 색상 규칙
의미 기반으로만 사용. 장식용 색 금지.

| 의미 | 색 | 적용처 |
|------|----|-------|
| 정상 | 초록 | 설비 상태 원, 도넛 정상, 전월대비 감소 화살표 |
| 이상 | 빨강 | 설비 상태 원, 도넛 이상, 전월대비 증가 화살표, 빨간 띠/빨간 점 |
| 실제값 | 녹색 실선 + marker | 추이 그래프, 일일 이상 그래프(9개 전부 녹색 한 색) |
| 예측값 | 파랑 점선 + marker | 추이 그래프 |
| 임계치 가이드 선 | 빨간 점선 | 이상탐지 전압·역률 그래프 |
| 임계 미만 구간 | 옅은 붉은 배경 띠 | 이상탐지 그래프 하단 |

**한달 그래프 KS 상 색상**
- 상전압·역률: R 갈색 / S 검정 / T 회색
- 선간전압: RS 적색 / ST 황색 / TR 청색
- 다크 모드: 검정 선 → 밝은 흰색 계열(범례 이름 유지).

**테마**
- 라이트/다크 두 모드. 초기값 OS 설정, 사용자가 고르면 기억.
- 모드 변경 시 그래프 선·눈금·글자 색 재계산 후 다시 그림. 어두운 배경에서도 가독성 확보.

## 6. 상태 연동 규칙
- `selected_equipment`는 2번 영역 목록과 이상탐지 버튼이 **공유하는 단일 전역 상태**.
- 2번 목록 클릭 → 이상탐지 탭으로 전환 + 그 설비 선택.
- 이상탐지 버튼 클릭 → 2번 목록 선택 표시 갱신(페이지 유지).
- 탭·설비를 오가도 날짜·설비·테마·기준(일일/한달) 유지.
- 에이전트에서 바꾼 임계치는 `thresholds`에 반영 → 이상탐지 그래프 가이드 선 갱신.

## 7. 엣지 케이스
- 데이터 없는 날짜: 드롭다운에서 선택 불가.
- 데이터 없는 구간: 선 끊기 또는 "데이터 없음"(0으로 채우지 않음).
- 이상 0건 도넛: 전체 초록 + "이상 없음".
- 1366×768 초과 콘텐츠: 지정된 내부 영역에서만 스크롤(전체 페이지 스크롤 금지).
