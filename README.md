- 기존 모델과 모든 AI 탐지 기록을 보존하고, 전압·역률의 큰 변화나 지속 조건에 맞는 내용을 **확인할 정보**로 모았습니다.

- 새 보고서는 생성 당시의 날짜·설비·적용 기준·근거를 고정합니다.

이 서비스는 과거 자료를 사용하는 체험 환경입니다. 기준 시점은 **2025-04-30 00:00, 한국시간**, 마지막 전체 실측일은 **2025-04-29**입니다. RTU 채널 1~5, 11~18의 13대를 사용합니다. 과제용 확인 기준은 실제 설비 안전·고장 기준으로 검증되지 않았습니다.

## 실행

저장소 루트에서 실행합니다.

```powershell
python -m pip install -r requirements.txt
python -m streamlit run dashboard_app.py --server.address 127.0.0.1 --server.port 8503
```

브라우저에서 `http://127.0.0.1:8503`을 엽니다. 포함된 캐시로 현황·예측, 4월 1~29일의 기본 확인 정보와 AI 원기록, 보고서 작성을 확인할 수 있습니다. 원본 대용량 CSV나 재학습은 필요하지 않습니다.

센서 확인 기준을 바꾸거나 날짜 중간 시점으로 재계산하려면 검증된 5초 원자료 캐시가 필요합니다. 기본 경로는 저장소 상위 `outputs/agent_data`이고, 다른 위치는 `MARGARET_SENSOR_CACHE` 환경변수로 지정합니다. 자료가 없으면 변경한 기준의 결과를 추정하거나 0건으로 표시하지 않습니다. [캐시와 실행 범위](docs/SENSOR_INSIGHTS_REVIEW.md#실행과-자료-범위)를 확인하세요.

### GPT 대화 설정

`OPENAI_API_KEY` 환경변수 또는 로컬 `.streamlit/secrets.toml`에 키를 설정합니다. `OPENAI_MODEL` 기본값은 `gpt-5-mini`입니다. 키가 없으면 간단 조회 모드로 동작하며 대시보드와 보고서 직접 작성은 사용할 수 있습니다. **키·비밀 설정·작성한 보고서는 커밋하지 않습니다.** 페이지를 열거나 보고서를 직접 작성하는 동작은 API를 호출하지 않습니다.

기존 개발 PC의 상위 Python 환경과 비밀 설정을 사용하는 보조 실행 방법:

```powershell
..\.venv\Scripts\python.exe tools\run_preview.py --port 8503 --enable-openai
```

## 3분 검토 순서

1. **현황·예측** 또는 **설비 점검**에서 2025-04-29를 선택하고 13대 카드가 모두 보이는지 확인합니다.
2. 3호기 또는 예비건조기의 **보기 →**를 눌러 확인 정보와 근거를 봅니다. 상세 설비를 골라도 전체 카드는 유지됩니다.
3. **AI 원기록 / 기록만 보관**을 열어 선별되지 않은 탐지도 보존되는지 확인합니다.
4. 점검 내용을 보고서로 가져와 필수 입력 → 담당자 종합판정 확인 → Excel 다운로드를 진행합니다.
5. 5월 31일을 선택해 실측 없음 안내가 나오고 마지막 실측일로 돌아갈 수 있는지 확인합니다.

화면의 **기준·집계 설명** 버튼으로 시작 가이드에 이동할 수 있습니다. 기준·집계·해석 설명을 이곳에 모았습니다.

## 결과를 읽는 방법

- **AI 탐지 구간**은 연속된 5초 AI 표본을 묶은 수이며 고장 사건 수가 아닙니다. 정상 표본·누락·날짜 경계에서 나눕니다.
- **확인 정보**는 AI 근거가 있는 센서 조건 구간이고, **묶음**은 같은 설비·상·유형·방향의 반복 정보를 모은 표시 단위입니다. AI 구간 수와 직접 비교해 감소율을 계산하지 않습니다.
- 표본 누적 시간, 개별 연속 시간, 묶음의 처음~마지막 시각은 서로 다릅니다. 관측된 시간대 수를 지속 시간으로 바꾸지 않습니다.
- 자료 없음 또는 추가 확인 정보 없음은 설비 정상·무고장을 뜻하지 않습니다.

전력 예측은 기존 Extra Trees를 유지했습니다. 요금은 180원/kWh, 탄소는 0.424 kgCO₂/kWh를 적용합니다. 5월 월 전체 예측은 744시간이며, 제공 정답과 비교한 5월 10일 00시~31일 00시의 505시간과 다릅니다. 이 검증에서 단순 평균 기준선 대비 개선은 확인되지 않았습니다. 정답의 Wh→kWh 해석은 제공자 확인이 남아 있습니다.

## 보고서

자동 근거 수집 → 필수 입력 → 담당자 종합판정 확인 → Excel 다운로드 순서입니다. 본문은 대표 내역, 별첨은 센서 확인 정보·묶음 및 기존 설정 기준·AI 전체 내역을 담습니다. AI 문구 제안은 담당자의 확인을 대신하지 않습니다.

작성 중 화면 날짜·설비·기준을 바꿔도 기존 초안은 덮어쓰지 않습니다. 새 대상·기준은 **새 보고서 시작**으로 적용합니다. 초안·양식·업로드는 브라우저 세션 메모리에 보관되므로 완성본을 내려받으세요. 제공되지 않은 계약전력·최대수요전력은 추정해 채우지 않습니다.
